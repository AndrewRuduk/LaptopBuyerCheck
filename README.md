# Проверка ноутбука перед покупкой

## Скачать на другой ноутбук

Откройте [репозиторий на GitHub](https://github.com/AndrewRuduk/LaptopBuyerCheck), нажмите **Code → Download ZIP** и распакуйте архив. Репозиторий публичный: скачать архив можно без входа в аккаунт GitHub.

Скопируйте распакованную папку целиком на флешку, включая `tools`. Запускайте `Run-Check.cmd` из распакованной папки, не из ZIP. Дополнительно скачивать smartctl или устанавливать программы не нужно.

## Быстрый запуск

1. Скопируйте всю папку проекта на флешку.
2. Дважды нажмите **Run-Check.cmd**. Подтвердите запрос Windows на права администратора для доступа к SMART.
3. Откроется браузер, проверка начнётся автоматически. Дождитесь результатов. При отмене запроса прав программа продолжит проверку без повышения прав; доступных показателей может быть меньше.

На главном экране крупные показатели:

- Батарея: остаточная ёмкость и износ в процентах, текущий заряд, циклы.
- Каждый накопитель: прямой SMART через встроенный smartctl — ресурс SSD, температура, наработка, ошибки данных/секторов, объём записи и аварийные отключения. Счётчики Windows используются как запасной источник.
- RAM: объём и частота; явно указано, что тест памяти не выполнялся.
- Устройства: число ошибок драйверов и названия устройств.
- Журнал железа: аппаратные/дисковые события за 30 дней.

Зелёный — доступный показатель без предупреждений, жёлтый/красный — конкретный сигнал, серый — нет данных или тест не выполнялся. Ресурс SSD рассчитывается как 100% минус SMART Percentage Used / Endurance Used; это оценка контроллера, не гарантия исправности. При отсутствии прямого счётчика используется Wear от Windows с отдельной подписью. Для HDD процент ресурса не выдумывается. Недоступность датчика не означает неисправность.

Полный отчёт раскрывается одним нажатием. Экран и клавиатура — две дополнительные проверки на той же странице. Сохранение HTML-отчёта только по кнопке; файл открывается без программы и интернета. Отметки нажатий клавиш не сохраняются.

В конце нажмите **Закрыть проверку**, чтобы остановить фоновую программу. Закрытие одной вкладки не останавливает сервер.

## Совместимость

Windows 10/11, встроенный Windows PowerShell 5.1, браузер, Windows Script Host. Ничего устанавливать не нужно. Если Windows Script Host отключён администратором, выполните в PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Check-Laptop.ps1
```

При запуске с флешки права администратора запрашиваются автоматически. Если их нельзя предоставить, отмените запрос. При запуске напрямую из PowerShell повышение прав не запрашивается. ExecutionPolicy Bypass действует только для текущего процесса.

## Что проверяется

Модель и BIOS, CPU, RAM, GPU, накопители и доступные SMART/счётчики, батарея и доступные циклы/ёмкость, устройства с ошибками, сеть, экраны, камера/звук/USB/Bluetooth и ошибки системы за 30 дней. Это диагностика доступных показателей, а не стресс-тест или проверка каждого компонента в работе.

Отсутствие ошибок не гарантирует исправность: Windows могли переустановить, журналы очистить, а датчики могут не поддерживаться. В полном отчёте недоступные данные показаны явно. Температуры ACPI не обязательно относятся к CPU/GPU. Остаточная ёмкость батареи менее 70% — ориентир для покупки, а не диагноз производителя. Историческая ошибка в журнале не обязательно означает текущую поломку.

Экран, корпус, петли, разъёмы, звук, камера, автономность и стабильность требуют проверки руками. При вздутой батарее прекратите использование. Fn, питание и системные сочетания браузер может не получать. Полноценную проверку RAM и тесты под нагрузкой выполняйте отдельно с согласия продавца.

Программа не меняет настройки и не отправляет данные. Постоянные отчёты создаются только по кнопке. Если WMI не возвращает ёмкость батареи, используется штатный powercfg: временный XML создаётся в системной папке временных файлов, читается и удаляется в блоке finally. При аварийном завершении процесса временный файл может остаться. SMART и счётчики запрашиваются отдельно для каждого диска, поэтому ошибка одного накопителя не скрывает показатели остальных. Сервер слушает только 127.0.0.1 на случайном порту с адресом сессии. Данные находятся в памяти. Браузер может хранить историю адресов. Сохранённый отчёт содержит идентификаторы и сообщения журналов; храните его приватно.

## Перенос на флешку и SMART

Копируйте **всю папку LaptopBuyerCheck**, включая `tools/smartmontools`. smartctl 7.5 уже внутри: версии x64 и x86, база накопителей, лицензия и исходники. На проверяемом ноутбуке установка, интернет, служба smartd и сторонние драйверы не требуются. Достаточно Run-Check.cmd и согласия на штатный запрос прав Windows.

Выполняются только команды чтения `--scan-open -j` и `-a -j -B ... -d ...`: без изменения настроек SMART, запуска самотестов, стирания и нагрузочных записей. На один запрос действует тайм-аут 20 секунд. Диски опрашиваются отдельно; недоступность одного не скрывает остальные. Поддержка SMART через отдельные USB/RAID-контроллеры зависит от оборудования. Исходный JSON и сообщения smartctl находятся в полном отчёте. SMART с флагом ошибки обрабатывается как результат диагностики, а не просто сбой команды.

Накопители сопоставляются по серийному номеру или однозначному сочетанию модели/объёма. Несопоставленные SMART-устройства показываются отдельно, чтобы не приписать показания другому диску. Нулевые ошибки отличаются от отсутствующих данных. Для NVMe число записей журнала ошибок не считается числом ошибок данных.

smartmontools получен из [официального релиза 7.5](https://github.com/smartmontools/smartmontools/releases/tag/RELEASE_7_5). Проверка SHA-256 встроена: при повреждении или замене smartctl чтение прекращается. Лицензия GPL-2.0-or-later и исходный архив находятся в tools/smartmontools.

Проверки разработчика: `Test-Battery.ps1` и `Test-Smart.ps1`. Для проверки ноутбука запускать их не нужно.
